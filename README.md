Cryptocurrency Price Tracker

Project Description

The Cryptocurrency Price Tracker is a Python-based application that collects cryptocurrency information from CoinMarketCap using Selenium WebDriver.

It helps users monitor the latest prices and market information of the top 10 cryptocurrencies.

Objectives

- To collect real-time cryptocurrency data.
- To display the top 10 cryptocurrencies.
- To store current data in a CSV file.
- To maintain historical price records.
- To analyze price changes.

Features

- Live cryptocurrency price scraping.
- Top 10 cryptocurrency data collection.
- 24-hour price change tracking.
- Market capitalization tracking.
- CSV data export.
- Historical data logging with timestamps.
- Price and percentage change filtering.
- Basic trend analysis.
- Headless browser support.

Technologies Used

- Python
- Selenium
- Pandas
- Chrome WebDriver
- Web Scraping
- CSV

Project Files

- "main.py" – Main Python program.
- "crypto_data.csv" – Stores the latest cryptocurrency data.
- "crypto_history.csv" – Stores historical cryptocurrency records.

Conclusion

This project helps users collect and monitor cryptocurrency market information. It also provides CSV files for storing and analyzing cryptocurrency data.
